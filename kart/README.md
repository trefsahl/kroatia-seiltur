# Kart — import til Google Maps og navigasjonsapper

To filer med samme innhold (alle havner/ankringsbukter fra havneguiden + de tre rutene):

- `seiltur-kroatia.kml` — for **Google My Maps** (vises i Google Maps-appen)
- `seiltur-kroatia.gpx` — for **navigasjonsapper og kartplotter** (Navionics, Garmin, OpenCPN m.fl.)

## Inn i Google Maps (via My Maps)

1. Gå til [mymaps.google.com](https://mymaps.google.com) på PC (innlogget med Google-kontoen dere skal bruke på ferien)
2. **Opprett nytt kart** → gi det navn, f.eks. «Seiltur Kroatia»
3. I lagpanelet: **Importer** → velg `seiltur-kroatia.kml`
4. Ferdig — alle havnene kommer som punkter med beskrivelse (type, le-retninger, notater), og rutene A/B/C som fargede linjer

**På mobilen underveis:** Google Maps-appen → profilbildet/menyen → **Lagret** → **Kart** → velg «Seiltur Kroatia». Da ligger alle punktene oppå vanlig Google Maps, og dere kan trykke på en bukt for å lese le-notatene. Tips: last ned offline-kart for Kroatia-kysten i Google Maps før avreise (Profil → Offlinekart), så fungerer det uten dekning.

## Inn i Navionics / kartplotter (GPX)

- **Navionics Boating-appen:** Meny → ruter/markers → importer GPX (eller åpne GPX-filen fra Filer-appen og «del til» Navionics). Da får dere alle buktene som markører i selve sjøkartet — dette er appen dere faktisk navigerer med.
- **Kartplotter om bord:** legg GPX-filen på minnekort/USB hvis plotteren støtter import (de fleste Garmin/Raymarine/B&G gjør det). Sjekk med charterselskapet hvilken plotter båten har.

## Viktige forbehold

- **Posisjonene er omtrentlige** (±~100 m) — gode nok til å finne bukta, ikke til å gå inn i den. Bruk øynene, sjøkartet og dybdemåleren.
- **Rutelinjene er skjematiske etapper**, ikke navigasjonsruter — de tar IKKE hensyn til grunner, skjær eller forbudssoner. Planlegg hver etappe i Navionics/sjøkart.
- Google Maps har **ikke sjøkart** (ingen dybder/grunner) — bruk det til oversikt, havneinfo og på land; bruk Navionics/plotter på sjøen.
